# STAT 303 Final Project: Benchmarking RNN, LSTM and GRU for Multivariate Oil Price Forecasting

## Project Overview
This repository contains the final project for STAT 303 at Parami University, supervised by Prof. Si Thu Aung. The primary objective of this research is to benchmark the predictive capabilities of three distinct deep learning architectures—Simple RNN, Long Short-Term Memory (LSTM), and Gated Recurrent Unit (GRU), for multivariate time-series forecasting.

The models are designed to predict the next day's Brent and West Texas Intermediate (WTI) crude oil prices based on a window of historical data that includes financial indicators and a geopolitical risk index.

Authors: Htet Khant Linn, May Mon Thant, Ming Thet Paing
